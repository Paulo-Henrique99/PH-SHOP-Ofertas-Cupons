PH SHOP — Landing Page Achadinhos, Cupons e Ofertas

O que foi atualizado:
- Visual mais vibrante, com amarelo, rosa, laranja, verde-lima e cartões ilustrados.
- Seção de cupons e descontos.
- Cartões visuais para as listas: Futebol; Tênis Masc e Femin; Acessórios Para Celular; PC e Notebook; Perfumes Masc e Femin; Carro e Moto; Achadinhos PH SHOP; Ofertas FITNESS; Minhas recomendações.
- Chamadas para o grupo e para listas do Mercado Livre.
- Layout adaptado para celular e computador, com botão fixo de ofertas no celular.
- Mascote da PH SHOP incluído.

ANTES DE PUBLICAR:
1. Abra script.js.
2. Troque COLE_AQUI_O_LINK_DO_GRUPO_WHATSAPP pelo link real do grupo.
3. Troque COLE_AQUI_O_LINK_DAS_LISTAS_MERCADO_LIVRE pelo link principal das listas.
4. Se quiser que cada cartão de categoria leve para uma lista específica, substitua os href="#listas" dos cartões em index.html pelos links reais de cada lista.
5. Abra index.html no navegador para testar e publique a pasta completa em uma hospedagem estática (por exemplo, Netlify).

Arquivos: index.html, style.css, script.js e assets/mascote-ph-shop.png.
